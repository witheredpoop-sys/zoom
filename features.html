Features

Every tool.
One menu.

Zoom is deliberately broad but never noisy. Each tab has a job, each module has real settings, and everything is one right shift away.

01 · Combat

Read the fight.
Win the trade.

Combat modules are built around timing instead of spam. Swap to a mace for the hit, break a shield at the right tick, place a cart where the target will land.

  • Mace Swap, Shield Breaker, Double Anchor and Anchor Macro.
  • Trigger Bot, Aim Assist and HitBox controls that stay readable.
  • Auto Cart, Auto Crystal and Auto Web with placement gates.
  • Auto Totem, Hover Totem and inventory totem handling.
16 combat modules
Real settings, not placeholders
02 · Movement

Move clean.
Land first.

Movement should feel like an extension of the keyboard, not a fight with the server. Zoom keeps the inputs light and the checks honest.

  • Fly with vertical control and a speed you can actually steer.
  • Click TP and route helpers for recovering a position.
  • Sprint and Jump Reset tuned for modern hit registration.
  • Scaffold, Elytra Swap and movement coordination that share state.

03 · Render

See more.
Guess less.

Renders should give you information, not a screensaver. ESP, Chams and tags are layered so the important thing is always the brightest thing on screen.

  • Player ESP, Storage ESP, Block ESP and Item ESP.
  • Chams, Nametags, Target HUD and Item Tags.
  • Post FX, Motion Blur, Jump Circles and custom skies.
  • Capes, skins and name protection that stay local.
26 render modules
Every option has a purpose
04 · DonutSMP

The server,
understood.

The Donut tab knows the map, the shards and the economy UI. It is the difference between a client that runs on DonutSMP and one that was built for it.

  • Chunk Finder, Sus Chunk Finder and Prime Chunk Finder.
  • Netherite Finder, Tunnel Base Finder and RTP Base Finder.
  • Region Map, scoreboard tools and auction helpers.
  • Anti-Vanish, Fake Item and Player Bypass.

The details

Small things.
Big difference.

The parts you notice after an hour, not in a feature list. These are the reasons the menu feels like it belongs in the game.

Sound design

Soft clicks, toggles and menu ambience with independent volume. Silence it all in one switch.

Six palettes

Water, ice, violet and more. The click GUI, HUD and launcher share the same palette.

Instant search

Type a module name and the whole client narrows down. Ctrl + F gets you there from anywhere.

Launcher

Microsoft sign-in, version picker, memory slider and a socials tab that opens the community.

Profiles

Settings persist per install and survive rebuilds. Your binds and toggles are where you left them.

Licence built in

Signed grants, device checks and offline verification. Your client stays yours.
