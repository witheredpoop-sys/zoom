Getting started

The basics.

If you have never used a Fabric client before, start here. The launcher does most of the work.

Zoom is a Fabric client for Minecraft 1.21.11. It adds a click GUI, an in-game HUD and 91 modules covering combat, movement, render, misc and DonutSMP-specific tools.

Press right shift in game. The Zoom click GUI opens over the world. Press it again or escape to close it.

Yes. The installer includes the launcher, which handles your Microsoft account, the 1.21.11 Fabric install and your memory settings. It also keeps the client jar up to date.

Windows 10 or 11, a 64-bit Java 21 runtime (the launcher can point at one), a Microsoft account that owns Minecraft, and Fabric 1.21.11 installed through the launcher.

Version

1.21.11 only.
Really.

No legacy branch, no compatibility mode and no 1.8 client hiding in a dropdown.

No. Zoom does not have a 1.8.9 client, a 1.8 module set or a 1.8 download. The only supported version is Minecraft 1.21.11 on Fabric.

There is no 1.8 build planned. The client is designed around modern 1.21.11 mechanics, not a backport.

Zoom is a Fabric mod and is launched through its own launcher. It is not a Lunar or Badlion module and is not loaded by those clients.

The general combat, movement and render modules work anywhere Fabric runs. The Donut tab is specific to DonutSMP and its systems.
