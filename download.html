What you need

Windows 10 or 11 (64-bit), Minecraft 1.21.11 with Fabric installed, and a Microsoft account that owns the game. The launcher uses the Java runtime bundled in the installer.

What is inside the MSI

The Zoom launcher and the obfuscated client jar, installed together. There is no separate download link to hunt down and no key to paste into a login box.

Install

Three steps.
No maze.

The launcher is the whole setup. It finds your Fabric 1.21.11 install and keeps the client jar in step with it.

STEP 0101

Download the MSI

Grab the installer above. It is a single file for 64-bit Windows 10 and 11.

STEP 0202

Run the installer

Pick an install folder and finish the wizard. Zoom appears in the Start menu with its own launcher.

STEP 0303

Launch 1.21.11

Open Zoom, press Play and wait for Minecraft. Once in game, press right shift to open the menu.
